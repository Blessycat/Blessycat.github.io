## 四种角色不一定对应四份完整参数

语言模型每生成一个 token，都在当前前缀状态下选择动作。问题和已生成内容构成状态 s_t，下一 token 是动作 a_t，整段回答结束后可以获得质量奖励。PPO 把这个自回归过程当作序列决策问题。

策略模型负责选择动作；价值模型估计从当前前缀继续生成时的期望回报；奖励模型或验证器评价回答；固定参考策略提供偏离约束。价值头可以与策略共享部分结构，奖励也可能是规则函数，因此“四个角色”是概念分工，不能机械翻译为四倍显存。

此外还有旧策略 π_old：它是生成当前批数据时策略的快照。旧策略记录在 batch 中的 log probability 必须固定；参考策略则可能是训练开始时的 SFT 模型，长期不变。把这两者弄混，PPO 概率比和参考 KL 都会失去原来的含义。

## 一轮数据怎样流动

先冻结本轮采样策略，给一组提示生成回答，保存动作、mask、旧 log probability、价值预测和结束原因。再对回答评分，把终局奖励与逐 token 的 KL 惩罚组合成回报。根据这些数据计算优势与价值目标，随后对同一批数据做有限次小批量更新。

最后重新采样，而不是无限重复训练一批旧轨迹。[PPO 原论文](https://arxiv.org/abs/1707.06347)的 clipped surrogate 允许有限的数据复用，但不把它变成可以任意消费历史回放的通用离策略算法。

这里有一个容易漏掉的时序：优势和旧 log probability 通常在更新前确定，并在这些更新中作为固定目标使用。如果每一步都用当前模型覆盖“旧概率”，比值会总接近 1，算法想控制的策略变化便被隐藏了。

## GAE 把价值误差向前传播

价值 V(s_t) 估计从状态 s_t 开始的回报。一步时序差分残差是：

$$
\delta_t=r_t+\gamma V(s_{t+1})-V(s_t).
$$

广义优势估计将这些残差按衰减系数累加：

$$
\hat A_t=\sum_{l=0}^{T-t-1}(\gamma\lambda)^l\delta_{t+l}.
$$

取三步轨迹，奖励为 (0,0,1)，价值为 (0.2,0.3,0.4)，终止状态价值为 0。令 γ=1、λ=0.9，则三个残差为 (0.1,0.1,0.6)，倒序计算得到优势 (0.676,0.64,0.6)。终点的好结果因此影响更早的动作。

λ 接近 1 时使用更多后续信息，通常减少对短期价值估计的依赖，但增加采样方差；λ 较小时更依赖价值函数，可能引入更多偏差。[GAE 原论文](https://arxiv.org/abs/1506.02438)讨论的就是这种偏差与方差权衡，不能把某个 λ 当成所有语言任务的固定最佳值。

终止与截断也要分开。真正回答结束，可以使用终止状态价值 0；达到最大长度而被强行切断，是否 bootstrap 取决于任务定义与算法实现。若把所有超长回答都视为自然终止，会系统性改变价值目标，尤其影响较长推理轨迹。

## clipping 限制激励，不是把概率锁进盒子

令当前与旧策略在采样动作上的概率比为 ρ_t：

$$
\rho_t(\theta)=\frac{\pi_\theta(a_t\mid s_t)}
{\pi_{\mathrm{old}}(a_t\mid s_t)}.
$$

PPO-Clip 最大化：

$$
L^{\mathrm{clip}}=
\mathbb E_t\left[
\min\left(\rho_t\hat A_t,\,
\operatorname{clip}(\rho_t,1-\epsilon,1+\epsilon)\hat A_t\right)
\right].
$$

假设优势为 1，ε=0.2，ρ=1.4，未裁剪项是 1.4，裁剪项是 1.2，取较小的 1.2；继续提高这项概率不再获得同样的目标收益。若优势为 -1，ρ=0.6，两个值为 -0.6 与 -0.8，取 -0.8；过度降低坏动作概率的激励同样被削平。

注意 clipping 没有强制所有概率比留在区间内。共享参数、其他样本的梯度和优化器动量仍可能把某些比值推得很远。它也不是全局 KL 上界，所以还应观察实际 KL、clip fraction、熵和质量指标，必要时采用提前停止等实现措施。

价值损失、熵奖励和参考 KL 可以与该目标组合，但权重及是否采用 value clipping 属于具体实现。不要把某个训练器总损失的所有项都归为 PPO 原始定义。

## 用 CPU 验证优势和目标方向

```python
rewards = [0.0, 0.0, 1.0]
values = [0.2, 0.3, 0.4, 0.0]
gamma, lam = 1.0, 0.9
advantages = [0.0] * 3
next_advantage = 0.0
for t in reversed(range(3)):
    delta = rewards[t] + gamma * values[t+1] - values[t]
    next_advantage = delta + gamma * lam * next_advantage
    advantages[t] = next_advantage

def clipped_term(ratio, advantage, epsilon=0.2):
    bounded = min(max(ratio, 1-epsilon), 1+epsilon)
    return min(ratio*advantage, bounded*advantage)

print(advantages)
print(clipped_term(1.4, 1.0), clipped_term(0.6, -1.0))
```

验收应检查优势与上述手算一致，并分别画出正优势、负优势时目标随比值变化的折线。这里输出的是要最大化的 surrogate；训练库通常最小化它的负数。把正负号弄反，训练仍可能产生平滑曲线，却在系统性降低好动作概率。

再把价值都设为零并令 λ=1，优势应还原为从每个位置计算的折扣回报；把终点奖励设为零，观察残差如何改变。这些对照能确认递推方向和终止处理，而无需运行神经网络。

## 从正确公式到可信训练

价值模型通常拟合某种回报目标。若使用刚才的 GAE 构造 λ-return，可取目标为旧价值加优势，即 (0.876,0.94,1.0)。它与三步完整蒙特卡洛回报 (1,1,1) 不同，差异来自 λ 小于 1 时引入的 bootstrap。不要在一个位置用 λ-return 训练价值，却在报告中把它称为完整回报。

这些目标在一轮策略更新中应按实现约定固定，而不是让目标随当前价值输出一起自由移动。否则价值 loss 可能通过两边同步变化而下降，却没有提高预测能力。一个便宜的诊断是冻结一份轨迹与目标，独立查看预测散点、平均偏差和解释方差，再与原始奖励尺度对照。

在真实 token batch 中，mask 是算法的一部分。prompt、padding、工具返回内容不应被当作策略自主采取的动作；EOS 是否计入动作，要在训练和 rollout 中一致。优势归一化应只使用有效动作，还要说明是全局 batch、每个提示还是每张卡分别计算。

日志至少并列记录任务奖励、参考 KL、价值预测误差、优势分布、长度、终止原因与 clip fraction。奖励上涨但长度快速缩短，可能是长度惩罚占据主导；价值 loss 下降但解释方差很差，可能只是目标尺度变化；clip fraction 很高，则可能是更新过强或旧概率记录有误。

个人主机上的进一步实验可以用两个状态、三个动作的表格策略和已知奖励，比较纯 REINFORCE 与 PPO 在同一批数据上多次更新的行为。验收重点是概率合法、旧概率固定、有限差分梯度方向正确和独立采样回报，而不是追求与论文相同的训练规模。
